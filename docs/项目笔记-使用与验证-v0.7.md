# 项目笔记使用与验证

日期：2026-10-28；应用版本：v0.7.0。

## 使用

选择项目后进入左侧“项目笔记”。左侧列表按更新时间倒序排列，可搜索标题或正文；右侧查看、编辑当前笔记。点击“新建笔记”，填写标题和正文，点击“保存笔记”。标题最多 160 字符，正文最多 100 万字符，可新建多篇。

正文支持普通文本，以及 Markdown 标题、列表、引用、链接和代码块。“编辑 / 预览”只切换显示，不自动保存。预览不执行原文 HTML 和脚本，不加载图片或附件。

“未保存”表示本地草稿有修改。切换笔记、项目、页面或刷新关闭前会提醒；可取消离开后保存，或确认放弃。删除需要确认。其他窗口编辑或删除同一篇笔记时，保留本地草稿并暂停覆盖保存；先保留需要的内容，再点击“加载最新内容”处理。

## 存储和升级

笔记是独立的 projectNotes 集合，按 projectId 归属项目，记录标题、原始正文及创建更新时间；时间由后端维护。项目存在笔记时不能直接删除，笔记不能跨项目移动。保存沿用资料修订号机制，冲突返回 409。

旧工作台启动时增加空集合，原项目、版本、环境和凭据保留。工作台资料导出及备份包含笔记；用户内容仅存本机，GitHub 提交不包含正文、数据库、备份或密钥。本次不增加笔记 MCP 工具。

## 验证

- 15 项后端测试通过，新增覆盖笔记增删改查、归属和修订号检查、原文保留、资料导出、项目删除保护、旧数据升级和重启持久化。
- 浏览器用虚构双项目验证多篇笔记创建、修改、搜索、删除确认与空状态，以及刷新后项目间资料隔离。
- 验证 Markdown 标题、列表、引用、代码块、链接和普通文本；HTML、脚本、危险链接及图片不执行或加载。
- 验证切换笔记、项目、导航及浏览器刷新时的未保存确认，并验证其他窗口更新时不覆盖草稿。
- 桌面和窄窗口检查通过，无横向溢出；浏览器无错误或警告。截图保存在本机忽略目录 output/playwright/project-notes-desktop-v070.png 和 project-notes-narrow-v070.png。
