## 启停

后台启动脚本成功创建实例，健康检查 ready。停止脚本正常退出应用；再次启动后项目、版本、两台服务器、发布和备份记录及凭据状态均保留。

正式目录通过 `npm run stop` 停止、`npm run start:background` 再次启动，并通过 `npm run status` 确认 ready。启动脚本的依赖哈希使用 .NET SHA256，已验证当前 Windows PowerShell 环境兼容。

停止期间浏览器轮询产生的连接拒绝属于受控停机结果，不代表应用内部异常；恢复连接后可继续使用。

最终交付使用默认端口 4173 和正式 data 目录，UAT 的项目、凭据、备份及模拟 Jenkins 不带入正式资料。
