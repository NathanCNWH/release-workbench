# v0.5 验证记录

日期：2026-10-21。真实连接和开发验收分开，所有验收服务、主机与凭据为本机受控或虚构资料。

## 自动化

10 项 Node 测试通过，TypeScript 检查和 Vite 构建通过。继承 v0.4 的持久化、秘密不回传、Jenkins 队列/构建、幂等与未知结果、备份和请求来源检查。

新增覆盖：

- 旧环境主机保留，任务的 serverIds 初始化为空；空主机环境可保存；不同服务多主机及复用持久化，跨环境主机引用被拒绝。
- 本机 SSH2 服务实际完成环境变量密码认证，核对读取的账号，无需在主机资料填写 username；密码认证空账号被拒绝。
- 官方 SDK stdio MCP 客户端实际对 project、service、environment、version、sql、config 完成新增、读取、编辑和删除；过期修订、越界访问、引用和固定版本删除受保护；可归档版本，不接收主机密码字段。
- 多版本排序、重复 SQL 合并来源、SQL/配置冲突、配置空白差异、未处理冲突拦截；发布预览在来源变化时失效，发布完成后快照不随源版本编辑而变化。

## 浏览器

独立端口 4176、独立数据目录与本机模拟 Jenkins：

- 创建环境仅有基本资料，无主机输入，创建后主机数量为零。
- 为 api、web 添加环境变量认证主机，无账号/密码框即可保存；api 关联两台，web 复用其中一台，发布卡片各自显示对应主机。
- 选两个版本，未处理冲突时“生成发布预览”禁用；分别选择 SQL、配置内容后可生成预览。
- 只发布 api、分支 test，本机模拟 Jenkins 返回成功。记录包含两个来源版本、最终 SQL 与配置、一个服务及两台主机，两个原版本仍存在。
- 发布快照页面显示来源和冲突取舍，可下载 SQL、配置和 JSON。浏览器控制台无错误或警告。
- 390 像素窄屏文档宽度为 390，无横向溢出。环境编辑期间通过资料 API 模拟外部 AI 更新，页面保留未保存修改并禁用保存，加载最新资料后可再次保存。

## 升级与边界

升级前停止应用，完整 data 备份到被 Git 忽略的 backups/pre-v0.5-*。用户原有项目、环境和凭据保留；受控验收数据不混入正式目录。旧版发布记录不重写。

最终启停脚本实测通过，默认 4173 服务为 v0.5.0、ready。与升级前备份逐项核对：项目、版本、原环境资料和加密凭据均一致，仅旧任务补上空 serverIds。使用正式 stdio MCP 只读连接枚举 12 个工具并成功查询项目。独立 UAT 实例已停止，正式应用保持运行。

没有调用用户真实 Jenkins，没有对用户真实 Linux 或 MySQL 执行操作，也没有执行合并的 SQL 或同步配置。数据库备份恢复未在本轮验证。
