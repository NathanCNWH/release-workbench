# v0.6 使用与验证

## 页面操作

- 项目切换：左侧项目按钮展开列表，支持方向键、Home/End、Enter 与 Esc；点击外部关闭。
- 服务排序：在“服务管理”拖动服务手柄到目标卡片，也可聚焦手柄按 Alt + ↑ / ↓；自动提交保存。环境、版本勾选与发布列表均使用该顺序。
- 主机维护：进入环境“服务与主机”，独立新增、编辑主机；从服务连接点拖到主机，或先点服务连接点再点主机。点击连线再“解除关联”不会删除主机。删除主机需确认；完成后保存环境配置。环境变量认证不填账号、密码。
- 版本涉及服务：新建时可选，也可草稿期间在“涉及服务”勾选并点“保存涉及服务”。可以全选、清空、搜索；就绪版本在详情顶部点“取消就绪”恢复草稿后继续编辑，归档版本需复制。
- 统一发布：版本页不再提供发布预览入口。部署记录中的发布入口仍可选择版本资料、环境、服务和分支，版本涉及范围不会自动变成发布选择。
- 发布预览（v0.6.1）：生成成功后直接进入居中确认框，正文滚动、底部操作固定；“返回修改”保留选择，重新生成后再确认触发，成功提交后进入进度。

## 数据兼容和 AI

版本新增 serviceIds，缺失时兼容为空列表；不从历史发布推导。服务 ID 必须属于当前项目且不能重复，版本引用的服务受删除保护。既有组件历史字段保留，实际构建结果继续以部署记录为准。

MCP 的版本新增、编辑和查询支持 serviceIds；项目、环境、SQL/配置、版本合并和 Jenkins 工具继续保留。合并与发布快照保存来源版本涉及服务的 ID 和服务资料，后续编辑不改写已保存的历史快照。

## 验证范围

- 13 项后端测试覆盖持久化、版本范围归属与去重、取消就绪后编辑、历史快照保留、归档保护、旧数据迁移、手动顺序重启保持、MCP 读写，以及既有合并、发布与备份行为。
- 浏览器使用独立数据目录、虚构主机和 Mock Jenkins，检查新增主机、拖线与点击关联、保存后刷新、服务拖动及键盘排序、项目菜单切换、版本服务勾选与保存。交互验证截图位于本机忽略的 output/playwright 目录。
- v0.6.1 浏览器验证包含十服务预览、固定底部操作、返回保留选择、重新生成、Esc 关闭、预期 HTTP 409 错误在当前框中展示、Mock 提交后进度和取消就绪后再次编辑；未触发真实任务。
- 真实网关服务及环境绑定仅写入用户本地数据，任务和部署记录只读核验；未实际触发用户 Jenkins Job。真实连接资料、日志和备份不提交 Git。

## 启动停止

在项目目录运行 `npm run start:background`，或双击“启动.cmd”；打开 http://127.0.0.1:4173/。停止用 `npm run stop` 或“停止.cmd”，查询状态用 `npm run status`。修改源码后需要重新构建并重启服务才能加载新后端；原数据目录及加密密钥保持保留。
