# Release Workbench 需求确认记录

日期：2026-10-20

本记录更新 v0.1 中的待确认事项，与旧设计冲突时以本记录和用户后续要求为准。目前仅授权前端页面样稿，后端实施等待页面确认。

| 原确认项 | 用户决定 | 页面和后续实现依据 |
| --- | --- | --- |
| Q1 运行形式 | 本地 Web | 单机浏览器工作台 |
| Q2 版本 | 各环境复用，默认年月日加后缀 | 默认格式 YYYYMMDD-01，同项目同日递增，可修改名称；版本归项目，部署结果归环境 |
| Q3 数据库 | MySQL，且每个版本维护脚本变化 | 版本内独立 SQL 清单、脚本内容、顺序、目标库及前后差异，不能只做数据库连接信息 |
| Q4 服务器 | Linux | 管理 SSH 连接和部署路径 |
| Q5 配置 | 本地文件，后续转入 Nacos | 首期固定本地文件到版本；Nacos 同步为后续能力，不做后台监听或双向自动覆盖 |
| Q6 发布配置 | 维护账密、路径，一键发布 | 管理服务器登录信息和路径，以及 Jenkins 地址、账号、凭据引用、Job 路径和参数；不安装 Jenkins 或建设 Job 编辑器 |
| Q7 AI 形态 | 项目本身不接入 AI，允许外部 AI 读取信息并调用一键发布 | 没有内置聊天、模型配置、模型 API Key 或 Agent；对外提供资料和发布接口，发布共用页面业务流程 |
| Q8 AI 接口形式 | 需要解释 Skill 与 MCP 的区别，尚未选择 | Skill 是供外部 AI 阅读的操作说明；MCP 是提供查询或调用能力的标准接口，均不要求工具调用大模型 |
| Q9 备份恢复 | 按推荐 | 接受原设计中的备份与恢复边界 |
| Q10 使用人数 | 单人单机 | 本地使用，无团队权限和局域网多用户流程 |

用户已追加确认外部 AI 可读取资料并调用一键发布。前端展示资料预览、导出和后续接口能力说明；真实发布接口、CLI、Skill 与 MCP 等到页面确认后的后端阶段实现。

## Nacos 同步说明

可以在后续通过 Nacos 官方 API 读取和发布配置，前提是配置服务器地址、认证、Namespace、Group、Data ID 以及本地文件对应关系。推荐先做“拉取远端 → 比较差异 → 按明确方向推送”，避免本地编辑和远端人工编辑互相覆盖。

首期仅显示文件及后续迁移说明，按钮不能声称已实现同步。

参考：[Nacos 配置获取与发布 API](https://nacos.io/docs/latest/guide/user/open-api/)。
