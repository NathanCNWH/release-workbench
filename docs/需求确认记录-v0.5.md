# 需求确认记录 v0.5

确认日期：2026-10-21。

- 发布时可勾选多个版本，合并为本次发布清单和快照，保留原版本；不另建合并版本，不合并 Git 分支。
- 合并按选定版本顺序，SQL 内容相同去重，SQL 同名不同内容、配置同路径不同内容需要人工选择；发布记录保留来源、选择和最终内容。
- MCP 支持项目、服务、环境、版本及 SQL/配置资料增删改查，并保留已有查询和 Jenkins 发布工具。资料编辑与执行 SQL、更新服务器配置是不同操作。
- 新建环境不填主机；环境内每个服务可关联多台主机，不同服务可以使用不同主机或复用主机。旧版主机保留待关联。
- 环境仍共用部署路径和单一 MySQL 连接；前后端 Jenkins 两套连接仍全局管理。
- SSH_NAME / SSH_PWD 认证无需填写登录账号和密码；其他认证方式仍维护账号和相应秘密。
- 服务默认分支只用于新环境任务初始值，已有任务的分支设置和发布时选择优先。
- 发布仅触发 Jenkins；SQL、配置人工处理。沿用 main 分支开发推送。
