## 浏览器验证

使用 Playwright CLI 驱动 Chromium 完成以下交互：

- 新建项目时新增服务，填写服务名、Git、默认分支；创建后项目服务页显示该清单。
- 新项目环境不继承其他项目的数据库、路径和任务绑定；在新环境绑定项目服务 Job。项目尚无版本时可打开发布预览、勾选服务，发布按钮可用。
- 修改示例环境的第二台服务器地址和共用路径，保存后环境列表反映更新；每个环境仍为单一 MySQL 连接。
- 环境任务按服务引用全局前后端 Jenkins；修改分支参数名并保存；新项目的任务绑定显示已修改的全局账号。
- 在全局 Jenkins 中输入虚构 Token 并保存，密码输入框清空，未保存真实秘密。
- 从项目服务清单选择 order-worker 加入版本，Git 为只读引用，填写版本分支后保存；AI 资料同步显示该版本变化。
- 发布中同时勾选 order-api 与 order-console，为前者选择 test_zy；后者显示使用 Job 自身配置；未绑定 Job 的服务不可勾选。
- 在开发预览中模拟一个服务失败，逐服务显示成功/失败，记录总状态为部分失败，保留所选分支。
- 通过本地只读 HTTP 服务器加载导出的单文件 HTML，验证服务选择、AI 资料和发布演示，构建完成后才显示最终成功结果。
- 1440 像素桌面及 390 × 844 窄屏查看发布弹窗；窄屏文档宽度和视口均为 390，无横向溢出。
- 导出的 HTML 请求列表只有本地文档 GET，没有外部业务请求；浏览器未发现未处理错误。
