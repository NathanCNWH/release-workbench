# 需求确认记录 v0.4

确认日期：2026-10-20。

用户已明确要求开始前后端开发、启动应用并提供启动停止脚本；并确认将 v0.3 前端带入 main，之后只在 main 迭代。

版本创建时不选择服务。版本过程中维护 SQL 和配置变化，最终发布时再确定服务与分支；从版本详情发起的发布关联当前版本，部署页保留独立发布。

其余关系保持：项目维护服务和 Git；环境归项目，一个环境可有多台 Linux 服务器、一个共用部署路径和一个 MySQL 连接；前后端两套 Jenkins 地址和凭据全局管理。

发布只触发已有 Jenkins Job。SQL 和配置由人工执行或更新；应用不做 SSH 部署、不接入模型，Nacos 留待后续。外部 AI 通过资料和 MCP 使用同一发布流程。

实现、启动、测试结果见 [启动与使用](启动与使用-v0.4.md) 和 [验证记录](验证记录-v0.4.md)。真实环境联调与受控本地测试分别报告。
