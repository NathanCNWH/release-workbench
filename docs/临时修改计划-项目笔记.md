# 项目笔记

日期：2026-10-28。状态：用户已确认，已完成实现、类型检查、构建、15 项后端测试及受控浏览器验证。

## 一、问题确认

当前工作台没有项目笔记入口。需要每个项目独立维护多篇笔记，优先支持 Markdown；现有 React 页面和本地数据库可以承载此功能。

## 二、调整后的结果

- 左侧增加“项目笔记”，切换项目后显示该项目的笔记。左侧为列表，右侧查看或编辑，空列表提供新建入口。
- 每篇笔记包含标题、正文、创建时间和更新时间；可新建、修改、删除，按标题或正文搜索，列表按最近更新时间排序。
- 正文采用 Markdown 源文编辑，提供“编辑 / 预览”切换；支持标题、列表、引用、链接和代码块，普通文本也可直接使用。不需要退化为仅 TXT。
- 点击“保存”后持久化，展示未保存状态；切换笔记、项目或离开页面时提醒处理未保存内容，删除前确认。
- 笔记归属项目，保存在本机数据库，纳入工作台资料导出与备份。GitHub 只提交功能代码和说明，不提交用户笔记正文。

## 三、本期做 / 不做

本期完成上述笔记管理和 Markdown 预览。不做附件、图片上传、富文本编辑器、协作、历史版本、自动同步或笔记专用 MCP 工具。
