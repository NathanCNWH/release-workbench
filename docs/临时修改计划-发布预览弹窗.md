# 发布预览弹窗调整

日期：2026-10-22。状态：用户已确认，并补充“就绪版本取消就绪后恢复编辑”；已完成实施、构建、13 项后端测试及受控浏览器验证。

## 一、问题确认

发布预览目前被追加在服务列表和版本资料之后，任务多时需要滚动到底部才能核对，生成后的反馈不明显。

就绪版本只有复制入口，后端也禁止恢复草稿，用户无法回到原版本继续编辑。

## 二、调整后的结果

点击“生成发布预览”成功后，窗口直接进入居中的“发布预览”确认框：

- 顶部显示项目、环境、关联版本和任务数量。
- 中间显示本次服务、Jenkins Job、实际分支与参数，以及关联版本的合并资料；内容多时仅正文滚动。
- 底部固定“返回修改”“关闭”“确认触发 Jenkins”。返回修改保留环境、版本、服务和分支，修改后重新生成预览。
- 只有点击最终确认才触发 Jenkins，提交成功后显示发布进度；错误在当前窗口展示。

窗口按“选择发布内容 → 发布预览 → 发布进度”切换，同一时间只显示当前步骤。

就绪版本详情顶部增加“取消就绪”，点击后原版本恢复草稿，可继续修改涉及服务、SQL 和配置，再次标记就绪。取消只改变版本状态，已有发布快照保留；已归档版本继续使用复制入口。

## 三、本期做 / 不做

完成发布预览展示和步骤切换、就绪版本恢复草稿。保留预览过期检查、重复提交保护和发布历史；不修改真实连接资料，不触发用户实际发布。

## 四、前后端改动范围

- 前端：发布对话框的预览步骤、固定操作区和必要样式，版本详情的取消就绪按钮及状态反馈。
- 后端：允许就绪版本只改状态恢复草稿，再单独编辑资源；已归档版本仍不能直接恢复草稿。更新 MCP 状态操作说明，接口和数据库结构不变。
- 更新使用说明，完成后构建、重启本地工具并按 main 流程提交推送。

## 五、验证方式

使用虚构项目和 Mock Jenkins，在多服务场景核对自动进入预览、正文滚动与底部按钮、返回保留选择、修改后重新预览、关闭不发布和提交后的进度显示；检查键盘焦点及 Esc。完成类型检查、构建及相关已有发布测试。

验证页面、API/MCP 取消就绪后可以编辑，禁止在取消状态的同一请求中修改锁定资源，历史快照不变；归档版本保护仍有效。
