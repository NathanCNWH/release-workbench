# Release Workbench 项目发布工作台

本地项目、环境、版本与发布资源管理工具。将代码仓库、分支和提交、SQL、配置变更、服务器、数据库备份、Jenkins 与部署记录关联起来，并向 AI 提供统一的操作入口。

**当前阶段：功能设计待确认。仓库只有设计资料，尚未开始应用开发。**

- [完整功能设计](docs/功能设计说明书-v0.1.md)
- [临时开发计划及确认清单](docs/临时开发计划-v0.1.md)

项目采用自主设计的管理核心，复用 Git、SSH、Jenkins 和数据库原生工具执行任务。拟采用 Windows 本地 Web 工作台，最终范围以确认清单为准。

## 本地目录

`D:\git_rep\release-workbench`

## 文档确认

先阅读功能设计中的页面与操作流程，再按临时开发计划中的 Q1 至 Q10 确认范围。需求确认后才创建应用工程和实现功能。

本仓库不保存服务器密码、数据库密码、Jenkins Token、SSH 私钥、实际数据库备份或生产配置。
